# MELAKA 1511 — RETAK SELAT

A single-player, first-person browser game set in an alternate-history Kesultanan Melayu Melaka.
One night in 1511 a rift under the estuary leaves sealed cargo from the future on the quay, and
three people — a palace guard, a shipwright and a harbour courier — each find part of what is
being done with it.

**Play it:** https://louisenda86.github.io/melaka-1511/

It needs a current desktop Chrome, Edge or Safari, a keyboard and a mouse. It renders with WebGPU
where the browser has it and falls back to WebGL 2. The first load is about 80 MB.

## Controls

| Action | Default |
|---|---|
| Move | W A S D |
| Sprint · Crouch · Jump / vault / climb | Shift · C · Space |
| Attack / fire (hold a blade for a heavy blow) | Left mouse |
| Aim down sights · raise shield | Right mouse |
| Reload · Shield bash | R · V |
| Blade · Primary · Sidearm · Found weapon | 1 · 2 · 3 · 4 |
| Interact | E |
| Codex · Pause | J · P or Esc |

Keys can be rebound in **Tetapan → Kawalan**.

## Chapters

1. **Fajar Retak** — the market at dawn, the raid, the chase onto the jong.
2. **Cap Palsu** — the palace at night.
3. **Tiga Gudang** — the customs quarter, and a choice.
4. **Retak Selat** — the last stand on the Great Jetty.
5. **Rimba Bota** — the mountain rainforest and its ogres. Open from the start: you begin with
   the keris, and a pistol and a carbine lie on the camp platform if you want them.

## About this build

- Spoken lines are not included here; they appear as subtitles (Malay, with English).
- The Jawi lettering has not yet been checked by a qualified reader.
- It has been tested by automated playthroughs, not yet by players. Expect rough edges.
- This repository holds only the built game, not its source.
